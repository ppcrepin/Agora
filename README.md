# Agora *(nom de travail)*

Une application quotidienne pour découvrir son propre système de valeurs.

Chaque jour, une question issue de l'actualité et quatre propositions à juger au
**jugement majoritaire**. On dit ensuite ce qui motive son jugement, puis d'où
vient cette conviction — des données, un ressenti, une expérience vécue, un
principe. Au fil des jours, un radar de valeurs se dessine.

Dans un groupe — une famille, une classe, une association — les votes restent
anonymes, mais les profils de valeurs sont partagés. On ne sait pas comment
l'autre a voté ; on comprend ce qui compte pour lui.
